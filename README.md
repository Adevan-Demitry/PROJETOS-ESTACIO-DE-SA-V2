## 👨‍💻 Sobre Mim

Sou formado em Análise e Desenvolvimento de Sistemas pela Estácio de Sá. Este repositório reúne projetos acadêmicos desenvolvidos durante minha formação, com aplicações práticas de programação, análise de dados, desenvolvimento mobile e banco de dados.

Os projetos exploram como a tecnologia pode ser aplicada para compreender necessidades reais, organizar informações e desenvolver soluções para diferentes desafios.

> # **4. EiraData: Análise Estatística Aplicada à Gestão de Condomínio**
>
> **Período Acadêmico:** 2025.1 | **Código:** DGT1344
>
> **Descrição:**
>
> Aplicação de estatística e análise de enquetes digitais no Condomínio Residencial Plano e Raposo-Eiras Garcia, com 399 moradores, para apoiar decisões relacionadas à infraestrutura e aos serviços.

>
