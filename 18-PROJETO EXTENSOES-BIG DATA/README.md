## Projeto de Extensão | EiraSpark: Big Data aplicado no condomínio

> [!TIP]
> # **Descrição:**
>
> Análise de dados de 399 moradores do condomínio, utilizando Big Data para identificar padrões e demandas relacionadas a estacionamento, bicicletário, mercado e área de lazer.
>
#
> [!TIP]
> # **Objetivo:**
>
> Desenvolver uma solução em Big Data para coletar, estruturar e analisar dados, classificar demandas por categoria e gerar insights para apoiar a tomada de decisão em um cenário real.
>
#
> [!TIP]
> # **Tecnologias:**
>
> Apache Spark | Python | Excel | Formulários | Modelagem de dados | K-Means (Machine Learning).
>
#
> [!IMPORTANT]
> # **Resultados e Aprendizados:**
>
> Apoio à redução de reclamações e à otimização do uso das vagas, além de contribuir para a implantação do minimercado. Aplicação prática de fundamentos de análise de dados, com desenvolvimento do pensamento analítico e da tomada de decisão orientada por dados.
