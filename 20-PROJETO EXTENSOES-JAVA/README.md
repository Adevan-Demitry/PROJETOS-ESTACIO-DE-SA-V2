## Projeto de Extensão | EiraSpark: Análise e Melhoria de Infraestrutura com Java


> [!TIP]
> # **Descrição:**
>
> Aplicação de conceitos de Programação Orientada a Objetos em Java em um cenário real, analisando dados de 399 moradores para apoiar melhorias no estacionamento, bicicletário e área de lazer, com foco na organização e privacidade das informações.
>
#
> [!TIP]
> # **Objetivo:**
>
> Desenvolver um sistema em Java para coletar e estruturar dados com segurança, analisar demandas da comunidade, propor melhorias com base em dados reais e apoiar a tomada de decisão, aplicando conceitos de abstração e encapsulamento.
>
#
> [!TIP]
> # **Tecnologias:**
>
> NetBeans | Java (POO) | JPA | Hibernate | JDBC | Formulários digitais.
>
#
> [!IMPORTANT]
> # **Resultados e Aprendizados:**
>
> Mapeamento das demandas da comunidade e propostas para redução de conflitos nas vagas. Base para o planejamento da área de lazer. Fundamentos de POO e persistência de dados aplicados na prática, com evolução na comunicação técnica e na compreensão do impacto social da tecnologia.
>
