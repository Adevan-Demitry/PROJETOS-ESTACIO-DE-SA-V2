## Projeto de Extensão | Desenvolvimento Rápido de Aplicações em Python

>
> Desenvolvimento de um sistema web para mapear necessidades sociais do bairro Jardim Maria Luiza (SP).

>
#
> [!TIP]

> Python | Flask | PostgreSQL | SQLAlchemy | Flask-Migrate.

#
> [!IMPORTANT]
> # **Resultados e Aprendizados:**
